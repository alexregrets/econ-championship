# Как проверить проект руками

## Что нужно один раз

```bash
pip install uv        # если uv ещё не установлен
uv sync               # создаст .venv и поставит зависимости (Python скачает сам)
uv run pytest -q      # все тесты должны быть зелёными
```

## Команды запуска

| Что | Команда |
|-----|---------|
| Дашборд профессора | `uv run streamlit run dashboard/app.py` |
| Ролевая оболочка (TUI в терминале) | `uv run python -m devshell.role_tui` |
| Обычный сидер (7 команд, симметричный раунд) | `uv run python -m devshell.seed` |
| Коды команд для бота (печать/генерация) | `uv run python -m devshell.team_codes` |
| Telegram-бот (long polling) | `uv run python -m bot.main` |

Обе программы работают с одним файлом базы `econ_tournament.db` в корне.
Кнопки «Seed» пересоздают базу с нуля — прошлые данные стираются.

## Чеклист: пройти раунд от создания до результатов (обе оси скора)

1. **Засеять ролевой пилот.** Запустить `uv run python -m devshell.role_tui`,
   нажать **«Seed + срезы»**. В журнале: 3 реальные компании (Роснефть, Лукойл,
   Сургутнефтегаз) и открытый раунд «Нефть РФ 2013».

2. **Сыграть за роли одной команды.** Нажать **«Статус»** (появятся id команд).
   Ввести в поле id команды `1`, нажать **«Финансист»** — видно только его
   данные (себестоимость 364 $/т). Ввести Q `100`, нажать **«Предложить Q»**.
   Затем нажать **«Маркетолог»**, ввести Q `140`, снова **«Предложить Q»**.

3. **Свести решение lead-ролью.** Нажать **«Lead: обзор»** — видны оба
   предложения, агрегат Q=120 и what-if (цена/прибыль, если конкуренты сыграют
   Нэш). Написать в поле «заметка» обоснование своими словами (например:
   «оценили спрос по цене Urals, наклон отрицательный, поэтому не наращиваем
   добычу») — этот текст потом оценит LLM. Ввести Q `120`, нажать
   **«Lead: зафиксировать Q»**.

4. **Зафиксировать решения остальных команд.** Ввести id `2`, Q `120`,
   заметку — и **«Lead: зафиксировать Q»**; то же для id `3`. Закрыть TUI
   (Ctrl+C).

5. **Закрыть раунд в дашборде.** Запустить
   `uv run streamlit run dashboard/app.py`, открыть страницу **«Раунды»**.
   Под открытым раундом — «Решений подано: 3 из 3». Нажать
   **«Закрыть раунд №1 и посчитать»**. В таблице результатов: цена ≈ 754 $/т,
   market score ≈ 46 854 (это млн $) у каждой команды, rubric score пока 0.0.

6. **Оценить обоснования (вторая ось скора).** Прописать ключ в `.env`
   (скопировать `.env.example` → `.env`, вставить `GROQ_API_KEY=...`),
   перезапустить дашборд. В разделе «Результаты закрытых раундов» нажать
   **«Оценить обоснования раунда №1 (Groq)»**. Колонка rubric score станет
   ненулевой (0–1 по рубрике). Без ключа кнопка покажет понятную ошибку, а
   рыночные числа не изменятся — это ожидаемое поведение.

7. **(По желанию) Симметричный раунд без ролей.** `uv run python -m
   devshell.seed` создаст 7 команд и открытый раунд; решения вносятся прямо на
   странице раунда формой «Внести решение команды», дальше — те же шаги 5–6.

## Чеклист: подача решений через Telegram-бота

1. **Токен.** Получить токен у @BotFather, вписать `BOT_TOKEN=...` в `.env`.

2. **Сид и коды команд.** `uv run python -m devshell.seed` (7 команд и
   открытый раунд), затем `uv run python -m devshell.team_codes` — печатает
   код для каждой команды (повторный запуск коды не меняет). Эти коды
   раздаются студентам.

3. **Запустить бота.** `uv run python -m bot.main` (long polling; без токена
   честно откажется стартовать). Оставить работать в терминале.

4. **В Telegram (любой аккаунт):** написать боту `/start`, затем
   `/join <код из шага 2>` — бот подтвердит команду. `/submit 120 оценили
   спрос по цене, наклон отрицательный` — бот запишет решение в открытый
   раунд (повторный `/submit` заменяет его, пока раунд открыт; десятичная
   запятая допустима: `120,5`). `/status` — показывает команду, раунд и
   поданное решение.

5. **Дальше как обычно:** закрыть раунд в дашборде (шаг 5 предыдущего
   чеклиста) — решение из бота участвует в расчёте наравне с внесёнными
   вручную. После закрытия `/submit` отвечает «нет открытого раунда», ничего
   не записывая.

Если что-то пошло не так: `uv run pytest -q` — тесты укажут, какой слой сломан.
